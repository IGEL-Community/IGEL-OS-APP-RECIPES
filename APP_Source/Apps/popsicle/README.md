# [Popsicle](https://github.com/pop-os/popsicle)

Linux utility for flashing multiple USB devices in parallel.

- Obtain Popsicle AppImage and zip it up - [Popsicle Releases](https://github.com/pop-os/popsicle/releases)

- Zip file into `Popsicle.AppImage.zip`

**NOTE:** Packed and tested with `Popsicle_USB_Flasher-1.3.3-x86_64.AppImage`
