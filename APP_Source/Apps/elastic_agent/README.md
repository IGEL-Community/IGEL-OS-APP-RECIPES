# Elastic Agent

Elastic Agent - single, unified way to add monitoring for logs, metrics, and other types of data to a host.

## [Download Elastic Agent](https://www.elastic.co/downloads/elastic-agent) DEB file and rename as `elastic-agent-amd64.deb`

Tested with: `elastic-agent-9.5.3-amd64.deb`

## [Fleet and Elastic Agent Guide](https://www.elastic.co/docs/reference/fleet)

## [Fleet Release Notes](https://www.elastic.co/docs/release-notes/fleet)

## Profile Settings to Enroll Elastic Agent

- Fleet URL
- Fleet Enrollment Token
